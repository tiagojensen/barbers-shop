# AMARAJL Barber Shop — prévia de landing page

Prévia comercial de uma landing page para apresentação ao barbeiro. O foco da primeira versão é vender a experiência e conduzir o visitante ao agendamento.

## Estrutura

```text
BarberShop/
├── index.html
├── imagens/
│   └── logo.png
├── css/
│   └── style.css
└── js/
    └── script.js
```

## Como visualizar

Abra `index.html` no navegador. Para uma apresentação mais fiel, use uma extensão de servidor local, como Live Server.

## Próxima etapa

Substituir as imagens remotas da galeria pelas fotos reais da barbearia e ligar o botão de agendamento ao WhatsApp, a um sistema de agenda ou a um formulário próprio.
